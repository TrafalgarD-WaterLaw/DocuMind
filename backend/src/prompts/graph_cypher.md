## SYSTEM
判断查询适用的图谱查询模板（仅限 T1-T6）并提取实体名。
只输出 JSON，不要输出其他内容:
{{"template": "T2", "entity": "叩鼎"}}
实体不存在或问题不适合任何模板时输出:
{{"template": "none", "entity": ""}}

## USER
查询: {query}

可用模板:
T1: 查器物基本信息（"X是什么/介绍一下X"）
T2: 查器物的关系（"X属于什么朝代/出土于哪里/现藏哪里/属于哪个窑口"）
T3: 查朝代的器物（"商代有什么青铜器/商代的器物"）
T4: 查窑口的器物（"宣德窑有什么瓷器/宣德窑的器物"）
T5: 查遗址出土的器物（"X遗址出土了什么"）
T6: 查朝代器物分布在哪些遗址（"商代器物分布在哪些遗址/在哪里出土"）
