## 测完面试怎么讲（对照表）

1. 五路各自解决什么问题 → semantic 语义近似 / question 常见问法 / bm25 精确术语 / graph 实体关系 / entity 来源锚定；加权 RRF 融合 + 来源多样性防单源垄断
2. 怎么防幻觉 → 硬拒答（空检索不调 LLM）+ 软拒答（CRAG 二次评估 + prompt 诚实约束）——B1/B2 就是现场演示
3. 多模态互检 → 图注路管"写什么" + CLIP 管"像什么"双路互补；删文档联动清 CLIP 索引（G5）保证数据一致
4. 上传文档变知识 → 解析→结构感知切分→父子分块→图注配对→hash 去重→双通道入库→任务持久化（G1-G4 全覆盖）
5. 评测证明有效 → eval Recall 100% / MRR 0.67-0.71 / faithfulness 71%；检索改动后跑 `eval/run_eval.py --retrieval-only` 防回归
