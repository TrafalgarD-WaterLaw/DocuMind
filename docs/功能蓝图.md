## 二、缺失 ❌

### P0 — 必做 (缺了就不是完整平台)

| 功能 | 说明 | 简历价值 |
|------|------|----------|
| **PDF 多模态解析** | 版面分析 + 表格识别 + 公式 OCR + 图片描述 → 结构化 Markdown | ★★★ |
| **文档上传 API** | 上传 → 解析 → 分块 → 入库 → 返回解析概览 | ★★★ |
| **通用接口抽象层** | LLM / VectorStore / GraphStore / Embedder / DocParser 五大接口 | ★★★ |
| **RAG 管道完整闭环** | 上传文档 → 自动入库 → 可检索问答 (现在只有固定知识库) | ★★★ |
| **索引管理** | 列出已入库文档、删除索引、重建索引 | ★★☆ |

### P1 — 核心技术亮点

| 功能 | 说明 | 简历价值 |
|------|------|----------|
| **混合检索升级 (HyDE)** | BM25 + FAISS → BGE-M3 dense+sparse 双路，或加 HyDE 假设文档增强 | ★★★ |
| **多 Agent 协作可视化** | 前端实时展示 Agent DAG (谁调用谁 / 耗时 / 产出)，不止是步骤列表 | ★★★ |
| **引用溯源** | 回答中标注信息来源 (文档名 + 页码 + 片段)，前端可点击跳转 | ★★☆ |
| **检索策略自适应** | 简单问题用快速检索，复杂问题多轮检索+重排序 | ★★☆ |
| **知识图谱自动构建** | 从文档自动抽取实体+关系入 Neo4j，不需要手写 CSV | ★★★ |

### P2 — 工程完善

| 功能 | 说明 | 简历价值 |

## 四、简历级功能全貌

```
多模态智能文档解析与知识管理平台

核心能力:
├── 📄 多模态文档解析
│   ├── 布局检测 (段落/标题/列表/代码块)
│   ├── 表格识别 → Markdown
│   ├── 公式识别 → LaTeX
│   └── 图片语义描述 (VLM)
│
├── 🔍 混合检索 RAG
│   ├── Dense + Sparse 双路召回
│   ├── HyDE 查询增强
│   ├── 引用溯源 (Source → Page → Snippet)
│   └── 流式 NDJSON 实时问答
│
├── 🤖 多 Agent 协作
│   ├── LLM 意图分析 → 任务分解
│   ├── 领域 Expert 并行分析 (可扩展注册)
│   ├── 结果合成 + 思维导图输出
│   └── 前端实时 DAG 可视化
│
├── 🕸️ 知识图谱
│   ├── 实体关系自动抽取
│   ├── 交互式力导向图
│   └── 节点展开 / 路径搜索
│
└── 🏗️ 工程架构
    ├── 接口驱动设计 (可插拔 LLM/Vector/Graph)
    ├── Docker Compose 一键部署
    ├── CI/CD 自动化测试
    └── 领域配置分离 (文物 / 论文 / 技术文档)
```

技术栈: Python, FastAPI, DeepSeek, Chroma, Neo4j, BGE-M3,
          Docling, Vue 3, TypeScript, ECharts, Pinia, Docker
